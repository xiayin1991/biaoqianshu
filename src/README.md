# 标签树

为教研老师设计的题集打标工具，让专家的判断可视化。

## 当前版本

- 版本：v1.7.1
- 技术路线：HTML UI + Python 本地后端 + pywebview + Portable EXE
- 支持导入：PDF、DOCX、PPTX、PNG、JPG、JPEG、WEBP、BMP

## 核心工作流

1. 点击“导入试卷”，系统自动新建项目并渲染整份试卷页预览。
2. 点击“框题”，在试卷页上拖拽黄色选框。
3. 点击选框右下角“确定”，录入题号和分值；系统保存框选区域并绑定题目 ID。
4. 在题目预览下方可直接修改题号和分值；题号会自动查重，冲突或格式错误时回退上一次有效值。
5. 在右下角录入标签，用 `/` 分级，例如：`平面几何/三角形/面积`。
6. 标签、题号和分值均实时保存；完成后直接点击“框题”继续下一题。
7. 使用“页”导航切换原试卷，使用“题”导航切换已框题目，修改题号、分值或标签。

## 标签树

- 根节点显示试卷名。
- 标签树从下向上生长。
- 节点显示标签名和贴标次数。
- 贴标次数越多，节点越大、连线越粗。
- 支持 1–10 层配色计算，实际通常不超过 3 层。
- 鼠标悬停节点时，在节点左上方显示完整标签路径。
- 节点括号内为关联题目次数；根节点显示一级子节点次数之和。
- 单题模式下根节点显示当前题号；整卷模式下显示试卷名。
- “整卷/单题”和“题数/分值”使用左右滑块切换。
- 顶部同时显示“标签累计”和“去重”：累计为所有题目标签条数之和，去重为不同完整标签路径数量。
- 标签输入框实时按完整标签中的字符检索，不限定在开头；支持模糊包含、字符顺序不敏感匹配、方向键选择、回车填充和鼠标点击填充。

## 导出

- 标签树 PNG：同时生成题数版和分值版。
- Markdown：直接渲染 SVG、Mermaid、默认展开的折叠树、题目明细、标签题目映射、分值排行、一级/二级分支统计、三级分值统计和父级统计。
- PDF：先生成两张 PNG 与 Markdown，再将题数版、分值版图形和完整 Markdown 统计区块整合导出。

## 项目文件夹

```text
Projects/<试卷名>_<时间>/
├─ source/         原始试卷
├─ pages/          原试卷逐页预览 PNG
├─ questions/      框选后的题目 PNG
├─ exports/        导出结果
└─ project.json    页码、题目、标签和参数
```

## 启动与打包

开发运行：

```powershell
.\run.ps1
```

重新打包：

```powershell
.\build_portable.ps1 -PythonExe "python.exe"
```

输出：

```text
dist-v171\标签树\标签树.exe
dist\标签树-Portable-v1.7.1.zip
```

## 已知边界

- 带文字层的 PDF 可以在后续自动切题功能中按题号处理。
- 当前正式流程采用人工框题，适配扫描版正卷和复杂版式。
- DOCX/PPTX 先转为整页文字预览，复杂版式与公式图片仍可能不完整。
